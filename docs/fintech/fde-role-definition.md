# FDE Role Definition

## What The FDE Does

The FDE sits with the desk and owns the delivery loop from idea to deployment. In fintech, that means translating investment intent into buildable work, keeping risk and compliance engaged, and making sure the desk can actually use what ships.

## Responsibilities

- Shape the idea before code starts.
- Choose the right entry point in the BMad workflow.
- Keep the PRD, architecture, and specs aligned.
- Coordinate reviews with Risk, Compliance, and Engineering.
- Keep scope tight enough to ship.

## What The FDE Is Not

- Not a ticket taker.
- Not a detached project manager.
- Not someone who bypasses governance to move faster.

## BMad Skills The FDE Uses

| Need | Skill |
| --- | --- |
| Shape a vague desk problem | `bmad-forge-idea` |
| Write or validate the thesis | `bmad-prfaq`, `bmad-prd` |
| Design the system | `bmad-architecture` |
| Split work into epics | `bmad-spec` |
| Build and verify | `bmad-build` |
| Close the loop | `bmad-retrospective` |
