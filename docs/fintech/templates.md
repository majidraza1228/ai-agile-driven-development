# Fintech Templates

## Investment Thesis PRD Template

Use `src/bmm-skills/plan/bmad-prd/assets/prd-template.md` as the base, then add:

- thesis and investment intent
- mandate or desk problem
- risk and compliance constraints
- data lineage and audit trail requirements
- explicit non-goals

## Risk Architecture Spec Template

Use the standard spec template, then add:

- risk data sources
- control points
- latency and refresh expectations
- escalation paths
- failure handling and audit logging

## Compliance Checklist Template

Use a short release checklist with:

- approved PRD
- approved architecture
- signed-off specs
- evidence retention confirmed
- release owner named
- retrospective scheduled
