# Approval Gates and Decision Points

## Gates

| Gate | Decision Owner | What It Checks |
| --- | --- | --- |
| Investment Committee review | PM / CIO / IC | The concept is worth funding and fits the mandate |
| Risk Officer validation | Risk Management | Assumptions, model risk, data provenance, and controls |
| Architecture review | Tech Lead / Architect | Data flow, dependencies, audit trail, and implementation safety |
| Readiness / compliance gate | Compliance | Controls, evidence, release readiness, and regulatory fit |
| Post-deployment retrospective | Desk + FDE | The system works in practice and matches the original intent |

## Rule

Do not advance to the next phase until the current gate is documented and approved.
